What is Astro?

A JavaScript ecosystem framework used to organize the content-focused pages of aldi.my.id.

A modern web framework

Build with JavaScript.
Ship less browser JS.

Astro is an open-source web framework for building content-focused websites. It supports JavaScript and TypeScript, and lets developers create reusable components using Astro's .astro format alongside HTML and CSS.

Astro renders pages to HTML by default and sends client-side JavaScript when interactive features need it. Its file-based routing and reusable layouts help keep larger websites organized.

In aldi.my.id, the src/ directory separates components, page routes, layouts, styles, utilities, and integrations.
